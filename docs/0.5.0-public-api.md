# Charts 0.5.0 public API review

This inventory records the accepted API decisions. Final coordinated package qualification, personal review, and publication approval remain separate release gates.

Source: `e7f428db5b8b4774e2e507e3040ccd391af16bc1`. All 100 names and three export keys reviewed: 69 KEEP / 31 REMOVE / 0 MOVE. All 19 runtime functions remain, and all three keys remain.

See the [migration guide](./migration-0.5.0.md) for each retired name and the [hardening evidence](./hardening-0.5.0.md) for executed boundary probes.

## Export keys

| Key              | Decision | Reason                                                                                                                                                                                   |
| ---------------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.`              | KEEP     | Typed factory, supported expression/row operations, and explicit application prop/config/result annotations; replace blanket model type export with a reviewed named export list.        |
| `./styles`       | KEEP     | Applications and CSS entrypoints explicitly opt into structural/accessibility/theme-token styles; CLI starters, Examples, Website, and chart docs use this separate CSS import boundary. |
| `./package.json` | KEEP     | Installed tooling can inspect package version and exports through explicit metadata access without private-path imports.                                                                 |
